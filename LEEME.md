# NoiseCut Studio

## Descargar la aplicación
1. Sube todos los archivos de esta carpeta a un repositorio en GitHub.
2. Abre la pestaña **Actions** del repositorio y selecciona **Construir NoiseCut Studio para Windows**.
3. Pulsa **Run workflow** o espera a que termine la acción iniciada al subir cambios.
4. Al terminar, abre la ejecución y descarga el archivo **NoiseCutStudio-Windows** en **Artifacts**.
5. Descomprime el archivo y abre `NoiseCutStudio.exe`.

## Usar el editor
1. Pulsa **Importar video / audio / imagen** y elige tus archivos.
2. Haz doble clic en un video o imagen para añadirlo a la línea de tiempo.
3. Selecciona un clip y ajusta **Reducción de ruido**; prueba entre 12 y 20 dB para voz.
4. Para comprobar los efectos, pulsa **Vista previa con efectos**.
5. Pulsa **Exportar video (MP4)** y elige dónde guardar el resultado.
